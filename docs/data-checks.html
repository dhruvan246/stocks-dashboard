Data checks

Each check reads the same number from two independent sources and lists where they disagree. Sums and size checks cannot catch a plausible wrong number — a second reader can. Findings are reported, never auto-changed: a real error is fixed through its correction ledger, and a difference that is not an error is recorded as accepted with the reason.
