Source: docs/xcheck.json, built by scripts/xcheck_run.py (runbook §214). “Explained” = a known, by-design difference (e.g. Yahoo never adjusts demergers); “Wrong side” is read from the prices themselves: a correctly adjusted series is continuous across a split, so the file whose own price jumps by the gap is the one that failed to adjust. A real error is fixed through its correction ledger; a difference that is not an error is recorded as accepted with the reason.
