How these numbers are made

Employee headcount for the Nifty-500, survivorship-free (includes names that have since left the index), read from each company's own annual report / BRSR filed on BSE. Annual figures (fiscal year ending March) — India does not report headcount quarterly.

YoY in the company list = the latest year on file against the year on file before it. Since = the latest year against the first year on file. Women = women ÷ (men + women) of the latest year that reports both. The price chart is the stock's own daily prices and is there only for context.
