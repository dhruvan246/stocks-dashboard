How to read this page Pending = the filing has an attachment, so the vision routine will read it on its next run (00:15 IST off-season; 4×/day in results season — the switch is automatic, from the filing counts). No PDF = the filing carried no attachment to read; these can only be filled when the exchange posts the XBRL. Vision-read figures for NSE names are an overlay applied only to empty cells — real XBRL always supersedes them. Counts come from the same module the routine uses to pick its work (scripts/results_pending.py), so this page and the routine can never disagree.
